# ❤️ Kalıpları Kır

**Kalıpları Kır**, kadınların toplumsal önyargılara karşı seslerini duyurmasını, kendi hikâyelerini paylaşmasını ve dijital ortamda dayanışma kültürünü güçlendirmesini amaçlayan bir platform projesidir.

Proje, kadınların deneyimlerini görünür kılmayı, toplumsal farkındalık oluşturmayı ve birlikte değişim yaratmayı hedefler.

## 🎯 Projenin Amacı

- Kadınların kendilerini özgürce ifade edebilecekleri dijital bir alan oluşturmak.
- Toplumsal önyargılara karşı kolektif farkındalık geliştirmek.
- Kadınlar arasındaki dayanışmayı dijital ortamda desteklemek.
- Kadınların hikâyelerini ve deneyimlerini görünür kılmak.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Sayfa yapısı ve içerik düzeni.
- **CSS3:** Görsel tasarım ve duyarlı arayüz.
- **JavaScript:** Sayfa etkileşimleri ve dinamik içerikler.
- **Python / Flask:** Backend geliştirme.
- **Git ve GitHub:** Versiyon kontrolü ve proje yönetimi.

### Gelecekte Değerlendirilmesi Planlanan Teknoloji

- **Three.js:** 3D animasyonlar ve etkileşimli deneyimler.

## 🌟 Projenin Hedefleri

- Kullanıcı dostu bir arayüz sunmak.
- Kadınların hikâyelerini paylaşabilecekleri alanlar oluşturmak.
- Toplumsal farkındalığı destekleyen içerikler sunmak.
- Mobil cihazlarla uyumlu bir deneyim geliştirmek.
- Dijital dayanışmayı güçlendirmek.

## 📁 Proje Yapısı

Projenin güncel klasör ve dosya yapısı, GitHub deposundaki gerçek dosyalara göre düzenlenmektedir.

## 🚀 Kurulum

1. Depoyu bilgisayarınıza klonlayın:
```bash
   git clone https://github.com/busrabuseecodes/Kaliplari-Kir.git
```
2. Proje klasörüne geçin:,
```bash
   cd Kaliplari-Kir
```
Frontend dosyalarını tarayıcıda açarak inceleyebilirsiniz.

Backend bileşenlerini çalıştırmak için gerekli Python bağımlılıklarının ve başlatma adımlarının tamamlanması gerekmektedir.
🤝 Katkıda Bulunma
Projeye katkıda bulunmak isteyenler aşağıdaki adımları izleyebilir:
1. Depoyu fork edin.
2. Yeni bir dal oluşturun:
```bash
   git checkout -b yeni-ozellik
```
3. Değişikliklerinizi commit edin:
```bash
git add .
git commit -m "Yeni özellik eklendi"
```
4. Değişikliklerinizi GitHub'a gönderin:
```bash
   git push origin yeni-ozellik
```
5. GitHub üzerinden Pull Request oluşturun.
